# O1 adaptation of Matt Pocock's implementation discipline

Implement the requested slice from the current specification and repository state.
Prefer existing Seams and vertical slices.
Typecheck regularly and run focused tests during implementation.
Run the complete relevant test suite before declaring completion.
Finish with a separate Standards review and Spec review.
Commit to the current main branch unless the user explicitly requires another integration strategy.
