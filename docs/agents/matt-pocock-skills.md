# Matt Pocock engineering skillset used by O1

This repository adopts the engineering discipline from `mattpocock/skills` (MIT):

- `codebase-design`: deepen modules and keep seams small.
- `tdd`: behavior-first vertical slices at public seams.
- `diagnosing-bugs`: establish a tight red-capable feedback loop.
- `implement`: implement, typecheck, test, then review.
- `code-review`: separate Standards and Spec reviews.
- `research`: verify infrastructure and API facts against primary sources.

Upstream: https://github.com/mattpocock/skills

The repository-local `AGENTS.md` is the O1 adaptation. These skills are process guidance, not a claim that another coding agent is currently running inside GitHub.
